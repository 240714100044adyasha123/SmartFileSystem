Production Ingestion Protocol

Direct Browser-to-S3 Multi-Part Transfer ensures high throughput and zero EC2 CPU degradation.

Client-Side PKCE Validation: Verifies user identity claims via Amazon Cognito User Pool without leaking secrets.
Pre-Signed S3 Security: API Gateway restricts write access to a single object key with strict 15-minute TTL.
Serverless Event Trigger: AWS Lambda spins up instantly on S3 PutObject completion to extract metadata.
NoSQL Audit & Notification: Metadata persisted to DynamoDB, and alerts broadcast via Amazon SNS topic.

                    Academic AWS Cloud Architecture Blueprint
                

                
            

            

                

                    This system implements an enterprise-grade Decoupled Event-Driven Ingestion Architecture. File streams never bottleneck the EC2 instance; instead, the browser streams directly to S3 using short-lived IAM credentials.

                    Key Exam Viva Questions Answered:
                    
    
                        
  • Why not upload directly through EC2? Uploading multi-gigabyte files through EC2 saturates network interfaces, causes HTTP thread blocking, and increases bandwidth billing. Direct S3 uploads scale infinitely with zero EC2 overhead.
    • 
                        
  • How is security maintained without backend credentials in frontend? AWS Cognito authenticates the client via PKCE. API Gateway verifies the JWT token and creates a temporary Pre-Signed S3 URL valid only for the specific file name, MIME type, and a short 15-minute expiration window.
    • 
                        
  • What is the role of EC2 in this project? The EC2 instance acts as the dedicated host for the high-availability web client, serving static assets via Nginx, monitoring health endpoints (`/health`), and acting as the management portal.
